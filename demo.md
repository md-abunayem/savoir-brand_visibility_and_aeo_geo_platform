# Fieldnote hackathon submission

## Project description

Fieldnote is a small seed-library app built with Codex. A visitor opens the returns FAQ to find out where an envelope belongs. Kane CLI checks the page title and clicks the question in Chrome. When the browser finds a defect, Codex can inspect the failed step and propose a patch. A human reviews the change before Kane repeats the same interaction. Each run keeps its native screenshots and reported usage in an encrypted case linked to the tested commit.

[Fieldnote repository](https://github.com/md-abunayem/savoir-brand_visibility_and_aeo_geo_platform)

Use actual footage for each result segment. A capture of the local page can introduce the app. Keep credentials, signed links, private case files and account balances out of the recording. Review any screenshot before making it public. The submission needs a YouTube URL and the two published post URLs.
