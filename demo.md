# Fieldnote demonstration

## Video script, about four minutes

| Time | Screen | Narration |
| --- | --- | --- |
| 0:00–0:30 | Local seed-library page | “A reader wants to return a seed envelope. The answer is in the document, but pressing the question does nothing. Can we prove what changed from the reader's point of view?” |
| 0:30–1:05 | Architecture and synthetic page | “Codex helped build this standalone experiment. Kane controls Chrome on a standard GitHub runner. The browser sees a small synthetic site. The private case stores the original browser evidence.” |
| 1:05–1:50 | Actual title and original FAQ records, once available | Show the validated title, original interaction, failed-step screenshot count and measured credits. Read the actual outcome. A missing screenshot ends this segment as an infrastructure finding. |
| 1:50–2:45 | Private review, with credentials and account details omitted | Show the genuine model choice, its evidence reference, and the proposed native disclosure. Show the human examining the baseline and proposed revision. Record only the approved, sanitized view. |
| 2:45–3:35 | Repaired page and actual recheck | Click the same question. If the recheck passed, display the equal objective hash and the different page revision hashes. Read the actual before/after screenshot counts and usage. |
| 3:35–4:00 | Reviewed comparison | Explain what the two browser records establish for this single FAQ. Show the public source URL and local preview command. |

Until both records exist, record a fixture walkthrough labelled **local preview**. Leave live-result segments unrecorded. An illustrative FAQ click cannot stand in for the provider evidence.
